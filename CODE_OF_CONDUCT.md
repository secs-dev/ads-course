# Норма поведения

## NDA

1. Ваш репозиторий с решением задач должен быть приватным. Не искушайте коллег.
   Если вы сделаете публичный форк данного репозитория (он будет виден) в
   счетчиках или если вы сделаете PR с решением ЛР в данный репозиторий, то
   преподаватель вправе отвергнуть выполненную студентом работу и потребовать
   выполнение нового варианта задания.

## LLM

1. Студенту не рекомендуется использовать LLM для решения основных задач
   лабораторной работы (например, реализация ключевой логики). Цель
   задания -- освоение материала.

2. Использование LLM не осуждается при углублённом изучении теории
   (исследовании), создании вспомогательных скриптов.

3. При использовании LLM для генерации артефактов рекомендуется
   грамотно и последовательно подходить формулировать промпты и
   прикладывать их к отчету по ЛР.

4. При неспособности студента ответить на простой вопрос про устройство
   созданных им артефактов, преподаватель вправе отвергнуть выполненную
   студентом работу и потребовать выполнение нового варианта задания.
